# برنامهٔ ده‌روزهٔ کامیت

کد نهایی کامل است. هر روز فقط بخش همان روز را (با کامنت‌های `/* ---------- ... ---------- */` در app.js جدا شده) به پروژه اضافه کن، اجرا کن، و کامیت بزن.

| روز | کار | پیام کامیت |
|---|---|---|
| ۱ | README، index.html خالی با `<main id="view">`، manifest | `chore: init project skeleton and README` |
| ۲ | بخش helpers و data در app.js | `feat: add data model and localStorage persistence` |
| ۳ | viewAdd، کیبورد عددی، saveForm، استایل فرم | `feat: add expense entry form with numeric keypad` |
| ۴ | viewList، txRow، edit/delete با واگرد | `feat: transaction list with edit, delete and undo` |
| ۵ | بخش Jalali و date sheet | `feat: Jalali dates and date picker` |
| ۶ | openCatSheet و بخش دسته‌ها در settings | `feat: custom categories` |
| ۷ | viewReport (جمع، دسته‌ها، مقایسه) | `feat: monthly report with category breakdown` |
| ۸ | بودجه، دونات و نمودار روزانه | `feat: budgets and charts` |
| ۹ | export/import، theme، sw.js، آیکون‌ها | `feat: backup, dark mode, offline PWA` |
| ۱۰ | تست روی گوشی، رفع باگ، انتشار Pages | `docs: deploy to GitHub Pages and polish` |

نکته: هر روز اول با `git status` ببین چی عوض شده، بعد `git add -p` بزن تا بدونی چی کامیت می‌کنی.
