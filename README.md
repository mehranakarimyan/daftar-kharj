## ✨ امکانات

- **ثبت سریع:** کیبورد عددی بزرگ، انتخاب دسته، توضیح اختیاری. دکمهٔ «۰۰۰» برای هزارتومانی‌ها و واگرد بعد از هر ثبت.
- **تاریخ شمسی:** امروز، دیروز یا هر تاریخ دلخواه؛ ماه‌ها و روزها طبق تقویم جلالی.
- **خرج و درآمد:** جدا ثبت می‌شن تا مانده یا کسری ماه مشخص باشه.
- **گزارش ماهانه:** جمع خرج، مقایسه با ماه قبل، نمودار دونات دسته‌ها، نمودار روزانه، میانگین روزانه، بزرگ‌ترین خرج و پرخرج‌ترین روز.
- **بودجه:** بودجهٔ کل ماه و بودجهٔ هر دسته. اپ می‌گه تا آخر ماه روزی چقدر می‌تونی خرج کنی.
- **دسته‌های دلخواه:** اسم، ایموجی و رنگ هر دسته قابل ویرایشه.
- **حالت شب:** با یه لمس، یا خودکار طبق تنظیم گوشی.
- **نصب روی گوشی و کار آفلاین:** مثل یه اپ معمولی (PWA).

## 🚀 شروع سریع

بدون نصب هیچ‌چیز، فقط یه سرور ساده لازمه:

```bash
git clone https://github.com/mehranakarimyan/daftar-kharj.git
cd daftar-kharj
python -m http.server 8000
```

بعد `http://localhost:8000` رو تو مرورگر باز کن.
سرویس‌ورکر (آفلاین) و رمزنگاری پشتیبان فقط روی `https` یا `localhost` کار می‌کنن.

**نصب روی گوشی:** اندروید (Chrome) منو ← Install app. آیفون (Safari) Share ← Add to Home Screen.

## 🔒 حریم خصوصی و امنیت

- **داده‌ها فقط روی دستگاه تو هستن.** حساب کاربری، سرور و ردیاب (analytics) وجود نداره.
- ذخیره‌سازی در **IndexedDB**، با مهاجرت خودکار از نسخه‌های قبل.
- **پشتیبان رمزدار:** AES-256-GCM با کلید مشتق‌شده از رمز تو (PBKDF2-SHA256). بدون رمز، فایل پشتیبان قابل باز شدن نیست.
- **CSP سخت‌گیرانه:** فقط اسکریپت و فونت از خود سایت اجرا می‌شه.
- هر چیزی که از بیرون وارد اپ بشه (فایل پشتیبان، داده‌های ذخیره‌شده) فیلد به فیلد بازسازی و پاک‌سازی می‌شه.
- خروجی CSV در برابر تزریق فرمول اکسل محافظت شده.

> ⚠️ اگه رمز فایل پشتیبان رو فراموش کنی، راهی برای بازیابی اون نیست.

## 💾 پشتیبان‌گیری

از **تنظیمات ← داده‌ها و پشتیبان**:

| کار | توضیح |
|---|---|
| پشتیبان رمزدار | فایل `.enc.json`؛ پیشنهادی |
| خروجی اکسل | فایل CSV برای تحلیل بیشتر |
| بازیابی | هم فایل رمزدار، هم ساده |

اگه مرورگر رو پاک کنی یا گوشی رو عوض کنی، داده‌ها ممکنه از بین برن؛ پس هر چند وقت یه بار پشتیبان بگیر. اپ بعد از ۳۰ روز بی‌پشتیبانی یادآوری می‌کنه.

## 🧱 ساختار پروژه

```
index.html               صفحه
style.css                ظاهر (روز و شب)
app.js                   منطق برنامه و نمایش‌ها
storage.js               لایهٔ ذخیره‌سازی وب (IndexedDB)
storage-sqlite.js        لایهٔ ذخیره‌سازی اپ اندروید (SQLite)
secure.js                رمزنگاری پشتیبان
sw.js                    سرویس‌ورکر (آفلاین)
manifest.webmanifest     تنظیمات نصب
scripts/build-web.js     آماده‌سازی فایل‌ها برای اپ اندروید
capacitor.config.json    تنظیمات Capacitor
docs/screenshots/        تصاویر README
```

لایهٔ ذخیره‌سازی عمداً جداست تا نسخهٔ اندروید فقط همین فایل رو با SQLite عوض کنه.

## 📱 اپ اندروید

همین کد با Capacitor به یه اپ اندروید تبدیل می‌شه و داده‌ها رو تو SQLite روی گوشی نگه می‌داره. راهنمای ساخت: [docs/ANDROID.md](docs/ANDROID.md)

## 🛠 فناوری‌ها

جاوااسکریپت ساده (بدون فریم‌ورک و بدون build)، Capacitor، SQLite، IndexedDB، WebCrypto، Service Worker، و `Intl` برای تقویم جلالی.

## 🧑‍💻 توسعه

- بعد از هر تغییر در فایل‌های برنامه، `VERSION` را در `sw.js` زیاد کن تا کاربرها نسخهٔ جدید را بگیرند.
- فونت وزیرمتن اختیاریه: فایل `Vazirmatn.woff2` را در پوشهٔ `fonts/` بگذار (از [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn)). بدون آن از فونت سیستم استفاده می‌شه.
- کلید امضای اپ (keystore) و هر فایل رمز را هرگز در گیت نگذار.
