# دفتر خرج

وب‌اپ ساده برای ثبت خرج و درآمد روزانه و گزارش ماهانه، مخصوص دانشجوها. فارسی، راست‌به‌چپ، تاریخ شمسی، بدون نیاز به سرور (داده‌ها روی گوشی می‌مونن).

## امکانات
- ثبت سریع با کیبورد عددی
- دسته‌های قابل ویرایش
- گزارش ماهانه با نمودار و مقایسه با ماه قبل
- بودجهٔ ماه و بودجهٔ هر دسته
- پشتیبان JSON و خروجی CSV
- نصب روی گوشی (PWA) و کار آفلاین

## ساختار
- `index.html` صفحه
- `style.css` ظاهر
- `app.js` منطق برنامه
- `sw.js` و `manifest.webmanifest` آفلاین و نصب

## اجرا
فایل‌ها را با هر سرور ساده باز کن، مثلاً `python3 -m http.server` و بعد `localhost:8000`.

## انتشار
GitHub Pages: Settings > Pages > Deploy from a branch > main / root.
بعد از هر تغییر، `VERSION` در `sw.js` را زیاد کن.
