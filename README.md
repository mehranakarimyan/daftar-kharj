# دفتر خرج

وب‌اپ ساده برای ثبت خرج و درآمد روزانه و گزارش ماهانه، مخصوص دانشجوها. فارسی، راست‌به‌چپ، تاریخ شمسی، بدون سرور (داده‌ها روی دستگاه می‌مونن).

## امکانات
- ثبت سریع با کیبورد عددی، دسته‌های قابل ویرایش
- گزارش ماهانه با نمودار و مقایسه با ماه قبل، بودجهٔ ماه و هر دسته
- حالت شب
- ذخیره‌سازی در IndexedDB (با مهاجرت خودکار از نسخهٔ قبل)
- پشتیبان رمزدار (AES-256-GCM) و خروجی CSV
- نصب روی گوشی (PWA) و کار آفلاین

## ساختار
- `index.html`، `style.css`، `app.js` صفحه، ظاهر و منطق
- `storage.js` لایهٔ ذخیره‌سازی (بعداً برای نسخهٔ اندروید با SQLite عوض می‌شه)
- `secure.js` رمزنگاری پشتیبان
- `sw.js`، `manifest.webmanifest` آفلاین و نصب

## امنیت
- CSP سخت‌گیرانه: فقط اسکریپت و فونت از خود سایت
- همهٔ داده‌هایی که از بیرون میان (ذخیره‌سازی، فایل پشتیبان) قبل از استفاده فیلتر و پاک‌سازی می‌شن
- CSV در برابر تزریق فرمول اکسل محافظت شده
- کلید امضای اپ (keystore) و فایل‌های رمز رو هیچ‌وقت تو گیت نذار

## فونت (اختیاری، پیشنهادی)
فایل `Vazirmatn.woff2` رو تو پوشهٔ `fonts/` بذار (از github.com/rastikerdar/vazirmatn). بدون اون، فونت سیستم استفاده می‌شه.

## اجرا
`python -m http.server 8000` و بعد `localhost:8000`. رمزنگاری و سرویس‌ورکر فقط روی https یا localhost کار می‌کنن.

## انتشار
GitHub Pages: Settings > Pages > Deploy from a branch > main / root.
بعد از هر تغییر، `VERSION` در `sw.js` را زیاد کن.
